# 摘要时机与记忆检查

## 摘要时机

设置 → 摘要设置 → 本聊天摘要时机。点击保存后仅影响当前聊天，随聊天元数据保存。

- 逐楼（默认）：下一次正文请求之前，先完成最近有效 AI 楼的摘要与状态更新。失败、取消、切换聊天或生成前检查异常均中止本次正文请求。历史多楼缺摘须手动处理，不自动连续收费补摘。
- 按条数：累计指定数量的有效 AI 回复，再在下一次正文生成前批量处理。用户消息不计数。
- 按范围：填写酒馆显示的楼层编号，包含开始和结束楼层。例如 7–10，生成 #11 前处理该范围内尚未摘要的有效 AI 回复；范围外恢复逐楼处理。已经摘要的楼层不会重新收费生成。

批量等待期间保留未摘要正文，暂缓注入旧结构化“当前状态”，以最近正文为准。隐藏或不计入记忆的楼层不自动补摘。酒馆自己的上下文长度限制仍可能裁剪正文。

新的自动批量路径一次请求返回各楼摘要与状态变化，逐楼保存。超出已有的每批字符数或楼数上限时分块请求；仍沿用已配置的请求重试及候补渠道。失败不会自动改成逐楼请求。已经成功保存的楼层不会因后续失败而撤销。

停止按钮取消本次摘要及等待的正文生成，不自动标记番外。跟随酒馆主 API 时，宿主若不支持中断，请求可能仍在服务端完成，但晚到结果不会写入记忆。

## 记忆检查

新增导航入口“记忆检查”：

- 来源记录：搜索当前聊天各楼摘要、原文和完整状态记录，以及各级总结。可展开楼内面板，或直接修改状态字段、删除状态分组/普通数组条目。
- 当前档案：查看重放后的完整状态、生活细节、人物、物品、计划、场景、变量及模板。
- 上次注入：查看最近一次放行生成前柏宝书准备注入的状态、历史摘要、向量召回和时间提示。不是酒馆最终完整请求，不包含其他插件、角色卡和最终裁剪。
- 调用记录：最近 100 次本会话插件请求的任务、渠道、请求模型、耗时、状态；摘要接口提供 model 时也显示返回模型。主 API 不能提供模型名时明确显示未知。

修改来源记录会重算状态，并使包含该记录的上层总结失效，避免旧总结继续带入错误内容。不会自动改写其他楼里的相同描述，也不会修改原剧情正文（物品/变量旁注沿用现有同步逻辑）。计划和生活细节的新增数组使用序号作为稳定引用，因此不支持直接删除中间槽位；可以编辑内容，或在原有计划/人物页面移除当前条目。

所有检查数据仅涵盖当前聊天由柏宝书管理的记录。历史向量快照命中可在注入文本中查看，原记录仍需回来源聊天编辑。调用和注入快照仅存在于当前浏览器会话，刷新后清空；不记录密钥或整份请求。

## 验证

测试覆盖严格等待、API/JSON 失败拦截、停止后的迟到响应、聊天切换、重生成排除当前楼、批量阈值/范围边界、批量完整状态写入、禁止自动逐楼回退，以及来源编辑后的状态重放和祖先总结失效。
